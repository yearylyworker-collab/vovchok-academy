# Передача и запуск 24/7 — инструкция

Два блока: **Часть A — для тебя (как передать проект)** и **Часть B — для заказчика (как это работает и что делать)**.

---

# Часть A. Что делаешь ты перед передачей

## A1. Запуск backend 24/7 (бот + AI + напоминания + синхронизация)
1. В Emergent нажми **Publish** (кнопка справа вверху). Получишь постоянный адрес вида `https://<имя>.emergent.host`.
2. В настройках окружения опубликованного приложения проверь переменные:
   - `BOT_TOKEN` — токен бота от @BotFather
   - `RUN_BOT=1` — бот поднимается внутри backend
   - `EMERGENT_LLM_KEY` — ключ для AI (Claude + Nano Banana)
   - `MONGO_URL`, `DB_NAME` — база (ставится платформой)
   - `MINI_APP_URL` — адрес Mini App (после шага A2: `https://<аккаунт>.github.io/vovchok-academy/`)
   - `CHANNEL_ID` — канал для проверки подписки (см. A4). Пусто = проверка отключена
3. Пока backend работает — работают: AI-наставник, синхронизация прогресса и **напоминания через 2 дня**. Если backend выключить, Mini App продолжит работать, но без AI, облачного прогресса и напоминаний.

## A2. Публикация Mini App на GitHub Pages (бесплатно)
1. Кнопка **Save to GitHub** → репозиторий `vovchok-academy` (папка `/docs` уже подготовлена).
2. В GitHub: `Settings → Pages → Source: Deploy from a branch → Branch: main, папка /docs` → Save.
3. Через 1–2 минуты Mini App доступен по `https://<аккаунт>.github.io/vovchok-academy/`.

## A3. Связка Mini App с backend (обязательный шаг)
В файле `docs/index.html` строка:
```html
<script>window.VA_API_URL = "";</script>
```
Замени на адрес опубликованного backend с `/api` на конце:
```html
<script>window.VA_API_URL = "https://<имя>.emergent.host/api";</script>
```
Закоммить изменение (Save to GitHub). Без этого шага в Mini App не будет AI-разборов и облачного прогресса (прогресс останется только в телефоне).

## A4. Реальная проверка подписки на канал
1. Добавь бота **администратором** канала академии (право «Читать участников» достаточно).
2. В переменные backend впиши `CHANNEL_ID`:
   - публичный канал: `@имя_канала`
   - приватный канал: числовой id вида `-1001234567890` (узнать: переслать любой пост канала боту @userinfobot или @getidsbot)
3. После этого в боте появляется кнопка «✅ Проверить подписку» и она реально проверяет подписку (`getChatMember`). Если `CHANNEL_ID` пуст — кнопка скрыта, доступ свободный.

## A5. Кнопка меню в BotFather (важно)
BotFather перекрывает настройку из кода. Сделай один раз:
1. @BotFather → `/mybots` → выбрать бота → **Bot Settings → Menu Button → Configure menu button**
2. URL: `https://<аккаунт>.github.io/vovchok-academy/?lang=ru&v=v4`, подпись: `Academy`

## A6. Передача бота заказчику (2 варианта)
**Вариант 1 — передать существующего бота (проще для заказчика):**
- @BotFather → `/mybots` → бот → **Transfer Ownership** → указать аккаунт заказчика (у него должен быть Telegram Premium или выполнены условия Telegram). Токен при передаче сохраняется.

**Вариант 2 — заказчик создаёт своего бота (надёжнее и без ограничений):**
1. Заказчик пишет @BotFather → `/newbot` → получает **токен**.
2. Ты вставляешь этот токен в `BOT_TOKEN` на backend и перезапускаешь сервис.
3. Заказчик делает шаг A5 (кнопка меню) и A4 (добавить бота админом канала).
4. Старого бота можно отключить (`/deletebot`).

## A7. Передача кода
- Репозиторий GitHub передаётся заказчику: `Settings → Collaborators` или `Transfer ownership`.
- Состав репозитория:
  - `docs/` — Mini App (то, что раздаёт GitHub Pages)
  - `bot/` — `bot.py` (бот), `mentor.py` (AI), `reminders.py` (напоминания), `assets/` (13 картинок), `promo/build.py` (генератор картинок)
  - `backend/` — FastAPI (API прогресса, AI-эндпоинты, запуск бота)
- Пароли/токены **не** храним в репозитории — только в переменных окружения хостинга.

## A8. Чек-лист перед сдачей
- [ ] Publish сделан, backend отвечает на `https://<backend>/api/`
- [ ] GitHub Pages открывается, `window.VA_API_URL` прописан
- [ ] `/start` в боте выдаёт фото + 4 инфографики + кнопки на всех трёх языках
- [ ] Кнопка «Войти в академию» открывает Mini App внутри Telegram
- [ ] В профиле Mini App статус «Синхронизировано ✓»
- [ ] `CHANNEL_ID` задан, кнопка «Проверить подписку» отвечает корректно
- [ ] AI отвечает на вопрос в чате бота
- [ ] На балансе AI-ключа есть кредиты ($50)

# Часть B. Инструкция для заказчика

## B1. Что у тебя есть
1. **Бот в Telegram** — презентует академию: фото, 4 инфографики, кнопки. Работает на русском, украинском и арабском.
2. **Mini App (академия)** — открывается кнопкой «🎓 Войти в академию» и кнопкой меню «Academy»: 12 модулей, 50 уроков, практика на графиках, XP, уровни, достижения, профиль, сообщество.
3. **AI-наставник** — ученик пишет боту любой вопрос по трейдингу и получает ответ; в практике AI разбирает конкретную ошибку.
4. **Напоминания** — если ученик не заходил 2 дня, бот сам присылает мотивационное сообщение с кнопкой возврата.
5. **Облачный прогресс** — XP, серия дней и достижения хранятся на сервере и привязаны к Telegram-аккаунту: ученик меняет телефон — прогресс на месте.

## B2. Как ученик проходит путь
1. Открывает бота → `/start` → выбирает язык.
2. Смотрит презентацию (фото + 4 инфографики, приходят сами).
3. Подписывается на канал академии (единственное условие входа).
4. Жмёт «🎓 Войти в академию» → учится: уроки → практика → XP и достижения.
5. Пропал на 2 дня → бот возвращает его сообщением.

## B3. Что нужно от тебя (владельца)
- **Канал академии**: бот должен быть админом канала, чтобы проверять подписку.
- **AI-кредиты**: держать баланс ключа (≈$50 хватает примерно на 1 000 активных учеников в месяц; расход виден в панели, можно включить автопополнение).
- **Хостинг backend**: $10–25/мес — от него зависят AI, облачный прогресс и напоминания. Mini App на GitHub Pages — бесплатно.

## B4. Как менять контент и тексты
| Что менять | Где |
|---|---|
| Уроки и практики | `docs/lessons-m1.js` … `lessons-m12.js` (в каждом объекте поля `ru`, `uk`, `ar`) |
| Тексты интерфейса | `docs/content.js`, `docs/content-lab.js` |
| Ссылки (канал, партнёр) | `docs/app.js` (объект `CFG`) и `bot/bot.py` (`CHANNEL`, `PARTNER`) |
| Тексты и кнопки бота | `bot/bot.py`, словарь `T` (ru/uk/ar) |
| Тексты напоминаний | `bot/reminders.py`, словарь `TEXTS` (4 варианта на язык) |
| Инфографики | `bot/promo/build.py` → запустить `python bot/promo/build.py`, картинки перезапишутся в `bot/assets/` |
| Главное фото приветствия | заменить файл `bot/assets/welcome.png` |

После изменений в `docs/` — коммит в GitHub (Pages обновится сам). После изменений в `bot/` или `backend/` — перезапуск backend.

## B5. Если нужно перенести на свой сервер (VPS, альтернатива)
```bash
git clone <репозиторий> && cd vovchok-academy
python -m venv .venv && . .venv/bin/activate
pip install -r backend/requirements.txt
# создать backend/.env: MONGO_URL, DB_NAME, BOT_TOKEN, RUN_BOT=1, EMERGENT_LLM_KEY, MINI_APP_URL, CHANNEL_ID
uvicorn server:app --host 0.0.0.0 --port 8001 --app-dir backend
```
Для 24/7 — systemd-юнит:
```ini
[Unit]
Description=Vovchok Academy backend + bot
After=network.target

[Service]
WorkingDirectory=/opt/vovchok-academy
EnvironmentFile=/opt/vovchok-academy/backend/.env
ExecStart=/opt/vovchok-academy/.venv/bin/uvicorn server:app --host 0.0.0.0 --port 8001 --app-dir backend
Restart=always

[Install]
WantedBy=multi-user.target
```
`sudo systemctl enable --now vovchok` — сервис поднимается сам после перезагрузки. Нужен MongoDB (локально или MongoDB Atlas — бесплатный тариф подходит).

## B6. Частые вопросы
- **Бот молчит на вопросы** → закончились AI-кредиты или не задан `EMERGENT_LLM_KEY`.
- **Напоминания не приходят** → backend выключен; они отправляются только при работающем сервисе.
- **«Проверить подписку» всегда отвечает «не вижу»** → бот не админ канала или неверный `CHANNEL_ID`.
- **Прогресс не синхронизируется** → в `docs/index.html` не прописан `window.VA_API_URL` или backend недоступен.
- **Кнопка меню открывает старый адрес** → поменять URL в BotFather (шаг A5), настройка BotFather имеет приоритет.
