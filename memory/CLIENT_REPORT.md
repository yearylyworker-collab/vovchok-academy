## 1. Что сдаётся (полный состав продукта)

### 1.1 Telegram Mini App (обучающее приложение внутри Telegram)
| Блок | Что сделано | Как работает |
|---|---|---|
| Обучение | 12 модулей, 50 уроков, 74 страницы контента | Пошаговый плеер уроков: текст → график-пример → вывод. Прогресс отмечается автоматически |
| Practice Lab | 13 практических сценариев, 4 варианта ответа (A/B/C/D) | Анимированный график «проигрывается», ученик выбирает решение, получает проверку и разбор ошибки. Фильтры по темам и сложности, режим «слабые темы», повтор |
| Геймификация | XP, 5 уровней, 8 достижений, серия дней (стрик), статистика точности | XP начисляется за урок (+10), практику (+5), модуль (+20), серию (+5). Уровни: Новичок → Ученик → Трейдер → Аналитик → Мастер |
| Профиль | Общий прогресс, XP, уровень, модули, стрик, достижения, слабые темы, выбор языка, статус синхронизации | Всё считается из реального прогресса ученика |
| Сообщество | Карточка официального канала + карточка партнёра ComfortTrade + цитата-баннер | Кнопки ведут в канал и к партнёру |
| Локализация | Русский, Українська, العربية (включая правильную RTL-вёрстку для арабского) | Язык берётся из Telegram или выбирается вручную; переведены и интерфейс, и весь контент уроков |
| Дизайн | Ночная «премиум»-атмосфера: анимированный фон, свечи, луна, неон, волк-наставник с мимикой, вибро-отклик (haptic) | Полностью кастомный UI, без шаблонов |
| Дисклеймер | Предупреждение о рисках на каждом экране | Требование для обучающих трейдинг-продуктов |

### 1.2 Сохранение прогресса на сервере (новое)
- XP, серия дней, достижения, пройденные уроки и практики хранятся **в базе на сервере**, а не только в телефоне.
- Привязка к Telegram-аккаунту ученика: подпись `initData` от Telegram проверяется криптографически (HMAC-SHA256 с токеном бота) — подделать чужой прогресс нельзя.
- Слияние без потерь: если ученик учился на двух устройствах — XP и стрик берутся максимальные, уроки и достижения объединяются.
- В профиле видно статус: «Синхронизировано ✓ · Привязано к твоему Telegram» + кнопка «Синхронизировать сейчас».
- API: `POST /api/progress/sync`, `POST /api/progress/reset`, `GET /api/progress/{uid}`. База: MongoDB, коллекция `progress`.

### 1.3 Telegram-бот — презентация и воронка (новое оформление)
- `/start` → первое сообщение: выбор языка (🇷🇺 / 🇺🇦 / 🇸🇦).
- Дальше бот **сам, автоматически**, выдаёт презентацию с паузами ~1,5 сек (видно «Волчок печатает…»), без лишних кнопок:
  1. 🐺 главное фото академии;
  2. 📊 текст о трёх решениях на графике;
  3. 🚀 инфографика «Как получить доступ» (4 шага);
  4. 📚 инфографика «Программа академии» (12 модулей);
  5. ⚡ инфографика «Что внутри» (возможности);
  6. 🤖 инфографика «Волчок-наставник» (AI);
  7. 🎯 финальное сообщение с кнопками: «📣 Подписаться на канал», «🎓 Войти в академию», «🤝 ComfortTrade», «🐺 Подсказка от волка» + дисклеймер.
- Все тексты и кнопки — с эмодзи, в трёх языках. Инфографики сделаны в фирменном стиле академии **отдельно под каждый язык** (12 картинок) + главное фото.
- Постоянная нижняя клавиатура («Академия», «Цитата дня», «Язык») убрана — как и просили.
- Гейт подписки: при заданном `CHANNEL_ID` кнопка «Проверить подписку» реально проверяет подписку через Telegram API (`getChatMember`).
- Картинки кэшируются по `file_id` — второй и последующие показы моментальные и не тратят трафик.

### 1.4 Напоминания ученикам (новое)
- Сервер помнит последнюю активность каждого ученика (заход в Mini App или сообщение боту).
- Если ученик не заходил **2+ дня**, бот сам присылает мотивационное сообщение с кнопкой «🎓 Войти в академию».
- Тексты персонализированы: подставляются реальные XP и число пройденных уроков. 4 варианта на каждый язык, чередуются, чтобы не повторяться.
- Периодичность: не чаще одного раза в 2 дня, пока ученик не вернётся. Проверка очереди — каждые 30 минут.
- Тексты фиксированные (не через AI) → **напоминания не тратят ни центa AI-кредитов**.

### 1.5 AI-наставник «Волчок» (Claude Sonnet 4.6)
- В боте: любой вопрос по трейдингу текстом → персональный ответ в роли наставника (до 120 слов, на языке ученика).
- В практике: кнопка «Спросить Волчка, почему» → AI объясняет именно ту ошибку, которую сделал ученик.
- `/quote` → мотивационная карточка: цитата (Claude) + сгенерированная картинка (Google Nano Banana).
- Жёсткие правила в системном промпте: **никаких сигналов, прогнозов по активам, обещаний дохода**; напоминание о рисках. Это защищает проект юридически и репутационно.

### 1.6 Инфраструктура
- Frontend: статика в папке `/docs` → бесплатный хостинг GitHub Pages.
- Backend: FastAPI + MongoDB, в нём же живёт бот (polling) и планировщик напоминаний → один сервис, один счёт за хостинг.
- Автотесты: 14 backend-тестов на API прогресса + сквозной тест восстановления прогресса после очистки телефона + локальный тест сценария бота (все пройдены).

## 2. Расход на нейросети (сколько хватит $50)

Тарифы поставщиков (2026): Claude Sonnet 4.6 — $3 за 1 млн входных / $15 за 1 млн выходных токенов. Генерация картинки Nano Banana (1K) — ≈ $0.067.

| Действие | Средняя цена | На $50 |
|---|---|---|
| Ответ наставника в боте | ≈ $0.004 | ≈ 12 500 ответов |
| Разбор ошибки в практике | ≈ $0.005 | ≈ 10 000 разборов |
| Карточка «цитата дня» (текст + картинка) | ≈ $0.069 | ≈ 720 карточек |
| Уроки, практика, XP, профиль, напоминания, синхронизация | $0 | без ограничений |

**Реалистичный месяц при $50 кредитов:**
- 5 000 ответов наставника → $20
- 3 000 разборов практики → $15
- 200 карточек-цитат → $14
- **Итого ≈ $49** — это примерно **1 000 активных учеников в месяц** (по ~12 AI-обращений на ученика).

Вывод для счёта: **$50 AI-кредитов = запас минимум на 1–3 месяца работы школы.** Расход виден в панели, автопополнение можно включить. Если учеников станет больше — стоимость растёт линейно и предсказуемо: ~$0.05 на активного ученика в месяц.

### 3.4 Аргументы для заказчика (почему это стоит своих денег)
1. **Продукт, а не бот-рассылка**: полноценная академия с программой, практикой и геймификацией — ученик остаётся в воронке неделями, а не 5 минут.
2. **Три языка сразу** (ru/uk/ar с RTL) — расширение на арабский рынок без доп. разработки; обычно это отдельный счёт +40% к бюджету.
3. **AI-наставник 24/7** — заменяет ручные ответы в поддержке; расход $0.004 за ответ против нескольких минут времени человека.
4. **Прогресс на сервере** — ученики не теряют XP при смене телефона, поэтому не бросают обучение; плюс у владельца появляется база активности учеников.
5. **Автоматический возврат учеников** — напоминания через 2 дня простоя работают без участия человека и бесплатно (без AI).
6. **Юридическая аккуратность** — дисклеймеры и жёсткий запрет на сигналы/обещания дохода зашиты и в приложение, и в AI-промпт.
7. **Всё принадлежит заказчику** — код, картинки, контент; нет привязки к платному конструктору и абонплате.
